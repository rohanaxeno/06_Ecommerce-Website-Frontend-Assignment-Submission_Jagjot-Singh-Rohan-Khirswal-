# Shop.co - E-Commerce Website

A responsive e-commerce frontend built as a frontend development
assignment.

## Tech Stack

- HTML5
- SCSS
- JavaScript (ES6+)
- LocalStorage
- GitHub Pages

## Features

- Responsive homepage
- Product listing and product details
- Dynamic product rendering using JavaScript
- Product image gallery
- Color and size selection
- Quantity controls
- Add to cart
- Cart management using LocalStorage
- Remove products and update quantities
- Coupon functionality
- Order summary with subtotal, discount, delivery fee and total
- Checkout success popup
- Login authentication
- Protected Product and Cart pages
- Logout functionality
- Responsive desktop and mobile design
